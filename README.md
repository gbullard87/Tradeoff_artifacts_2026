# Tradeoff_artifacts_2026
This repository contains code and data associated with the manuscript "Separating biological signal from statistical artifact in trait trade-off inference" by Garrison W. Bullard and Donald A. Jackson.

##Associated manuscript/preprint

##Overview

Biological trade-offs are often inferred from correlations among model-derived parameters. This study examines how restricted sampling, estimation error, and nonlinear reparameterization can generate apparent parameter correlations in the absence of underlying biological covariance.

The repository reproduces:

1. Conceptual simulations of parameter unidentifiability
2. Thermal death time simulations and reparameterization
3. Calibration of an uncorrelated generating distribution
4. The parameter-correlation artifact test
5. Principal component and GWAS phenotype analyses
6. Reanalysis of behavioral reaction norms
7. Reanalysis of published thermal tolerance and plasticity datasets
8. Experimental-design simulations
9. Trade-off power analysis

##Description of files
Unidentifiability_code_10_26.Rmd: Contains code required for all figures, tables, and analyses in the manuscript. Relies on All_data.zip and Unidentifiability_functions.R
Unidentifiability_functions.R: Contains code for 3 custom and reproducible functions for the correlation identifiability test. Tests described in the main text.
All_Data.zip: Contains all data files required to run Unidentifiability_code.Rmd

Contents:
    -compiled_reanalysis_data_V2.xlsx: thermal tolerance data compiled by (Gunderson, 2023)
    -Great_Tits.csv: behavioral plasticity data for male great tits across breeding stages (from Araya-Ajoy and Dingemanse, 2016)
    -Soto_etal_data: Thermal death time and genetic architecture data from 100 isogenic lines of Drosophila melanogaster (from Soto et al, 2025)
    -GWAS_Results: phenotype files generated by the DGRPool web tool on thermal death time parameters obtained from Soto_etal_data
    -DGRP2_all.txt: phenotype estimates for GWAS data (created in .Rmd above)
    -Mussel_Sperm: Data associated with (Hadlow et al 2022) Mussel sperm longevity vs motility tradeoff.
    -Sticklebacks: Data associated with (Jolles et al, 2019). Three-spined stickleback boldness vs plasticity tradeoff.
